# Presca-AI

**Presca-AI** is an AI-powered productivity assistant built to streamline and automate everyday corporate workflows. Developed as part of the AI Skill Accelerator Programme, the application leverages state-of-the-art large language models to help users save time and reduce manual overhead on routine tasks.

## Key Capabilities
* ✉️ **Email Generation** – Instantly drafts professional emails from rough notes or bullet points.
* 📝 **Meeting Summarization** – Transforms lengthy meeting transcripts into concise summaries and actionable items.
* 📅 **Task Planning** – Breaks down high-level project goals into structured, step-by-step checklists.
* 🔍 **Research Assistance** – Synthesizes complex information to provide quick, structured answers.
* 💬 **Chatbot Interaction** – Features an intuitive conversational interface for real-time task automation.

## Tech Stack
* **Language:** Python 3
* **Framework:** Streamlit (Web UI Application)
* **AI API:** Google GenAI SDK (Gemini Pro Model)

## How to Setup and Run Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   cd Presca-AI
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Set Up Your API Key:**
   Get a free Gemini API key from Google AI Studio and configure it in your environment or local Streamlit secrets.

4. **Run the Application:**
   ```bash
   streamlit run app.py
   ```
